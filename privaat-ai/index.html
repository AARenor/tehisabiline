Local AI arvuti sinu lauale, valmis ehitatud

Tuleme kohale, paneme kokku ja seadistame arvuti, mis jooksutab tehisintellekti ilma suure pilveta. Ei taha riistvara? Kasuta meie hostitud API-t – andmed tulevad meile Eestisse.

Kaks viisi pilvest välja

Local AI arvuti on sinu riistvara sinu ruumides: tuleme kohale, ehitame valmis, õpetame kasutama. Hostitud API on meie riistvara meie serveris Eestis: ühendad oma äpi otse, maksad kasutuse järgi. Mõlemal juhul ei satu su andmed suurettevõtte pilve.

Ehitus

Kuidas arvuti ehitus käib?

01

Kokkulepe

Räägime, milleks arvutit vaja ja mis eelarvega. Soovitame GPU ja ülejäänud osad.

02

Kokkupanek

Paneme arvuti kokku – kas meie juures või sinu juures kohapeal.

03

Seadistus

Paigaldame mudelid, häälestame eesti keele ja testime sinu päris tööga.

04

Õpetus

Näitame, kuidas mudelit kasutada, uuendada ja varundada. Jääme toeks.

Alternatiiv

Ei taha arvutit? Võta API

Hostime uncensored mudeleid oma serveritel. Otspunkt järgib OpenAI chat-completions liidese kuju, nii et olemasolev kood vajab tavaliselt ainult baasaadressi ja võtme vahetust. Ligipääs on võtmepõhine, limiitide ja kasutus-põhise arveldusega. Pilootfaasis avame ligipääsu taotluse alusel.

Näide

curl https://api.tehisabiline.ee/v1/chat/completions \
  -H "Authorization: Bearer SINU-VOTI" \
  -H "Content-Type: application/json" \
  -d '{"model": "tehisabiline-uncensored",
       "messages": [{"role": "user",
         "content": "Tere! Vasta eesti keeles."}]}'

Hinna kujunemine

Millest hind sõltub?

  • Arvuti: GPU ja muu riistvara valikust. Töö (kokkupanek, seadistus, õpetus) on selge paketihinnaga.
  • API: tegelikust kasutusmahust, võtmepõhiste limiitidega.

Kaardistuse järel saad hinna kirjas: osad, töö ja ajakava.

KKK

Küsimused local AI kohta

Kuidas local AI arvuti ehitus käib?+

Lepime kokku eelarve ja kasutuse, valime GPU ja korpuse, tuleme kohale, paneme kokku, paigaldame mudelid, häälestame eesti keele ja õpetame kasutama. Arvuti jääb sulle.

Mis vahe on local AI arvutil ja teie API-l?+

Local AI arvuti on sinu riistvara sinu ruumides: ühekordne ost, null kuumaksu. API on meie riistvara meie serveris: null algininvesteeringut, maksad kasutuse järgi. Mõlemal juhul ei lähe andmed suurettevõtte pilve.

Kus mu andmed API puhul asuvad?+

Meie enda riistvaral Eestis. Päringud tulevad meile, mitte Ameerika pilve. Soovi korral saab logideta režiimi, kus päringute sisu ei säilitata.

Millest hind sõltub?+

Arvuti puhul GPU ja muu riistvara valikust, API puhul kasutusmahust. Tasuta kaardistuse järel saab selge pakkumise kirjas.

Mida te ei tee?+

Ei aita ebaseadusliku tegevusega, ei testi võõraid süsteeme ilma omaniku kirjaliku loata ega mööda ligipääsukontrolle. Iga töö algab kirjalikest piiridest.
