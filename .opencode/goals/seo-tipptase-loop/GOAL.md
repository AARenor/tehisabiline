# Goal: seo-tipptase-loop

## Objective

Uuri parimaid viise SEO tipptasemele viimiseks ja ehita pidev SEO-paranduste loop tehisabiline.ee-le. Uurimus (tehniline SEO, sisu, struktuurandmed, kiirus, välised signaalid) + saidi audit + olulisemate paranduste teostus + korduvkasutatav SEO-loop (skript + ajastatud kontroll).

## Done when

- SEO uurimus valmis: tehniline/sisu/off-page praktikad allikate ja kuupäevadega dokumenteeritud
- tehisabiline.ee auditeeritud: puuduste nimekiri mõõtmistega (PageSpeed/SEO-check/katkised kohad)
- Top-parandused teostatud ja verifitseeritud (npm run test:seo läbib, live-kontrollid)
- Pidev SEO-loop olemas ja ühe täistsükli läbinud (skript + EVIDENCE)
