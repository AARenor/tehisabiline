OWASP API Top 10: mida kontrollida ja millist tõendit koguda

OWASP API Security Top 10 (2023) kirjeldab riskikategooriad, mitte kohustuslikku testipaketti. Allolev tabel seob iga kategooria kontrolli ja tõendiga, mida raportis oodata; töö ulatuse ja testkontod lepitakse kokku enne testi.

RiskMida kontrollitakseTõend raportis
API1 BOLAObjekti ID-ga päring teise kliendi/rolli objektilePäring ja vastus, oodatud vs tegelik tulemus
API2 AutentimineTokeni eluiga, refresh, brute force piirangudKatse kirjeldus ja vastuse koodid
API3 BOPLAVäljade tasemel õigused (nt roll, hind, staatus)Muudetud väli ja selle mõju
API4 RessursidPäringu suurus, lehekülje suurus, kiiruspiirangudPiirangute puudumine ja mõju
API5 BFLAAdministratiivsete funktsioonide ligipääs rolli järgiRoll, otspunkt ja vastus
API6 ÄrivoogTellimuse, allahindluse või maksevoogude kuritarvitamineSammud ja tulemus
API7 SSRFServeripoolsed päringud kasutaja antud URL-ileSihtkoha piirang ja vastus
API8 SeadistusCORS, veateated, HTTP meetodid, TLSPäis ja seadistus
API9 VarudVanad versioonid, dokumenteerimata otspunktidOtspunkti loetelu ja ligipääs
API10 TarbimineKolmandate osapoolte API-de usaldusAndmevoog ja valideerimine

Kordustest: mida uuesti kontrollida

  1. Vali leiud: kõik kriitilised ja need, mille parandus muutis autentimist või õigusi.
  2. Korda sama päringut: sama roll, sama kliendi keskkond (tenant) ja sama objekt, et tulemus oleks võrreldav.
  3. Kontrolli regressiooni: kas parandus ei avanud teist teed sama objekti juurde.
  4. Dokumenteeri: märgi, kas leid on suletud, osaliselt parandatud või endiselt avatud.

Kordustest ei ole kogu testi kordamine. Selle ulatus ja aeg lepitakse pakkumises kokku.

Küsimused kontrollnimekirja kohta

Mida see kontrollnimekiri sisaldab?

OWASP API Security Top 10 (2023) tabeli, mis seob iga riski kontrolli ja raportis oodatava tõendiga, ning kordustesti punktid.

Kas API pentest vajab OpenAPI kirjeldust?

See ei ole kohustuslik, kuid OpenAPI või Postmani kogu muudab ulatuse ja otspunktide katvuse kontrollitavaks ning vähendab testimüra.

Kuidas hinnata API pentesti tulemust?

Vaata kinnitatud leidude mõju, tõendeid ja parandussoovitusi, mitte ainult leidude arvu. Oluline on, kas leid on korratav ja kas parandus on kontrollitav kordustestiga.
