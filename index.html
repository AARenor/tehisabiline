  • Kordustest kokkuleppel

Keeldudeta küber-AI API

OpenAI-ühilduv API turvatööriistade arendajale: logid, kood ja konfiguratsioonid. API pole veel avalik – piloodis osalemist saab küsida e-kirjaga.

Korduma kippuvad küsimused

Mida tähendab keeldudeta ja piirangutega AI?

Keeldudeta (ehk tsenseerimata) tähendab, et mudel ei keeldu seaduslikust turvatööst, millest pilveteenused tihti keelduvad – näiteks oma süsteemi turvatestimise juhendamisest. Piirangutega tähendab, et ebaseaduslik tegevus on välistatud ning iga töö käib omaniku kirjaliku loa järgi.

Kas API on juba avalik?

Ei. OpenAI-ühilduv API on arenduses ja avalikku otspunkti veel pole. Piloodis osalemiseks kirjuta tehisabiline@gmail.com ning kirjelda turvatööriista ja kasutusjuhtu.

Mis on küberaudit?

Küberaudit on süsteemne kontroll: uuendused, ligipääsud, varundus, turvapäised ja sisendikontroll. Meie küberaudit on agendipõhine, iga olulise leiu vaatab üle inimene ja töö lõppeb parandusplaaniga tähtsuse järjekorras. Loe lähemalt küberauditi lehelt.

Kas pakute pentestimist?

Jah, kokkulepitud ulatuses ja süsteemi omaniku kirjaliku loa alusel. Pentestimine ehk läbitungimistest kontrollib, kas nõrkust saab päriselt ära kasutada. Tulemuseks on tõendid, parandusplaan ja kokkulepitud korduskontroll. Loe pentestimisest Eestis.

Kui palju see maksab?

API puhul sõltub hind kasutusmahust, auditi puhul süsteemide arvust ja sügavusest. Tasuta kaardistuse järel saad selge pakkumise kirjas.

Kas NIS2 mind puudutab?

Tõenäoliselt mitte otse: seadus kohustab suuri ja elutähtsaid tegijaid. Aga esmased meetmed kasvatavad iga ettevõtte vastupidavust. Loe NIS2 juhendit Eesti ettevõttele.
