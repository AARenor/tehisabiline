Company facts

  • Legal name: Tehisabiline OÜ.
  • Location: Tallinn, Estonia.
  • Founded: 24 September 2026.
  • Founder: Arle Aron Reidma.
  • Services: written-authorization cybersecurity audits and scoped penetration testing for web applications and APIs; a planned OpenAI-compatible cyber-AI API for security tooling.
  • Current status: the API is in development and not public. No endpoint, price or production availability should be assumed.

Tehisabiline does not claim 100% security, guaranteed savings, error-free AI or a certification it does not hold.

Boilerplate

Short version: Tehisabiline OÜ is a Tallinn-based cybersecurity company providing scoped audits and penetration testing under written authorization, with human review of significant findings. It is also developing a cyber-tuned API for legitimate security tooling.

Longer version: Tehisabiline OÜ works with Estonian organisations that need a clearer view of their web, API and AI security posture. Engagements start with a defined scope and written authorization; testing is limited to systems the client owns or controls. Significant findings are reviewed by a human, and the output is evidence, impact, a prioritised remediation plan and a retest option. The company is separately developing an OpenAI-compatible API for lawful security work; it is not yet publicly available.
