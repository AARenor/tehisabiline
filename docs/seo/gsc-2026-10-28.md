## Indexation state

`gsc_inspect.py` on `/cra/`, `/en/cra/`, `/kasutusjuhud/`, `/nis2/audit/`, `/en/nis2/audit/`: all `PASS`, "Submitted and indexed", robots `ALLOWED`, Google-selected canonical equals declared, last crawl 24–27 Oct.

arle.top: `/`, `/ai-arendus/`, `/ai-chatbot/`, `/ai-automatiseerimine/`, `/ai-agent/`, `/ai-konsultatsioon/`, `/tarkvara-arendus/` indexed (crawl 26–27 Oct). `/en/`, `/en/ai-arendus/`, `/artiklid/mis-on-ai-agent/` = "URL is unknown to Google".

Cause: GSC last downloaded `https://arle.top/sitemap.xml` on 26 Oct 11:04 and recorded 7 submitted URLs; the file on disk now lists 30. Re-submitting through the API is blocked — the ADC token only carries `webmasters.readonly`, and `PUT /sitemaps/...` returns `403 ACCESS_TOKEN_SCOPE_INSUFFICIENT`. The EN URLs are reachable from the ET pages (hreflang plus the `ET | EN` switch) and are in the sitemap, so this is a wait-for-recrawl item, not a code defect. A `gcloud auth application-default login --scopes=https://www.googleapis.com/auth/webmasters` would unblock API sitemap submission.

## Why the 18-page list is stale, not a defect

URL Inspection (live, per URL) on **all 58 sitemap URLs** returned `PASS`,
`Submitted and indexed`, `robotsTxtState ALLOWED`, `indexingState INDEXING_ALLOWED`,
Google-selected canonical equal to the declared one, last crawl 24–26 Oct. A URL cannot
collect impressions while unindexed, and several of the listed pages do. The Pages report
header itself dates the snapshot to 23 Oct, i.e. before the 24–26 Oct crawl wave. Recorded
as a reporting-lag discrepancy; **no page was changed on the strength of it**. Recheck the
Pages report after 29 Oct and only then treat a "Crawled – not indexed" entry as real.

The desktop read was still worth doing: it produced the only view of the redirect, 404 and
noindex buckets and confirmed `/saidikaart/`'s exclusion is the single intentional one.

## Demand check that shaped the content choices

Google Autocomplete (`hl=et,gl=ee` and `hl=en`), same method as `keyword-map.md`:

- Estonian long tail is nearly empty: `nis2 kuuluvus`, `nis2 kohaldub`, `nis2 sektorid`,
  `nis2 toiduaine`, `nis2 trahvid` return no suggestions. **Decision: no new Estonian
  sector pages, no standalone Estonian applicability URL.** The topical-map gaps for those
  are demand-free and would only add thin URLs.
- English long tail is dense: `nis2 audit checklist`, `nis2 audit requirements`,
  `nis2 compliance checklist`, `nis2 requirements checklist`, `nis2 requirements list`,
