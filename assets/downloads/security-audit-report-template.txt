WHERE THE TEXT IS DOING TOO MUCH — delete each line that applies
---------------------------------------------------------------
[ ] A finding with no criterion              -> add the clause or drop the finding
[ ] A finding with no evidence reference     -> this is an opinion, not a finding
[ ] "Best practice" as the only criterion    -> name the standard or the policy
[ ] "Critical" with no stated impact         -> say what breaks and for whom
[ ] A recommendation naming a product only    -> state the outcome it must achieve
[ ] An owner who is a team and not a person   -> name the accountable role
[ ] A due date of "Q3"                        -> use a date that can be missed
[ ] "Fully compliant" / "no risks found"     -> replace with what was reviewed
[ ] Findings that repeat last year unchanged  -> say so in 5.3 and escalate
