Avaleht/Küber-AI mudelid

Küberturbele häälestatud AI-mudelid

Üldmudelid on tehtud jutuks. Meie omad on peenhäälestatud turvatööle, vastavad seaduslikus raamis ka seal, kus pilv keeldub, ning hakkavad töötama meie riistvaral Eestis (riistvara tellitud).

Koostanud Tehisabiline OÜ · Viimati sisuliselt uuendatud 30. septembril 2026

Mis teeb mudeli küber-AI-ks?

Kolm asja: peenhäälestus turvaülesannetele (haavatavused, logid, konfiguratsioonid, koodianalüüs, ründepayload'ide käsitlus, red-teaming), refusal-free käitumine seadusliku töö puhul ning hostimine tulekul meie riistvaral Eestis (riistvara tellitud). Avatud kaaludega alusmudel on Qwen3.8-27B; refusal-free häälestus ja kasutuspiirid tulevad Tehisabiliselt, mitte alusmudeli nimest. Näiteks analüüsime sinu Nginxi konfi ja logilõiku kirjaliku loa mahus – seal, kus üldine pilve-AI keeldub.

  • Tsenseerimata ja EestisRiistvara on tellitud, majutus tulekul Eestis.
  • Refusal-free turvatööleSeaduslik turvatöö saab vastuse, ebaseaduslik mitte.
  • API arendajateleOpenAI-ühilduv otspunkt, võtmepõhine ligipääs.
  • Agendid + inimese kontrollIga oluline leid läbib inimese ülevaatuse.

Miks mitte tavaline pilve-AI?

  • Turvakeel. Võtab sisendiks CVE-ID, logilõigu või konfi; väljund vajab inimese kinnitust.
  • Ei keeldu tööst. Seaduslik turvatestimine oma süsteemidel saab juhised, mitte keeldumisteate.
  • Eesti majutus tulekul. Riistvara on tellitud. Töötlus hakkab toimuma meie serverites Eestis, mitte Ameerika pilves.
  • Andmeid ei koguta. Kasutame töötlemiseks ainult sinu sisendit: ei salvesta, ei treeni edasi, ei lekita kolmandatele.
  • AI Act. GPAI-kategooria, mitte kõrge riskiga süsteem. Tehniline dokumentatsioon hoitud.
  • Inimene kontrollib. Kriitilised leiud ja toimingud käivad inimese ülevaatusest läbi – ka agendipõhises töös.

Kas Eesti üldse vajab oma mudeleid?

Kasvav kasutus tähendab ka rohkem küsimusi: kuhu lähevad kliendiandmed, kui töötad USA pilve-AI-ga? Meie vastus on siin – mudel ja selle töötlus on Eestis.

  • 23,4%

    Eesti ettevõtetest kasutas 2025. aastal tehisintellekti – aasta varem oli näitaja veel ligi 14%.
    Allikas: OECD Economic Surveys: Estonia 2026

  • 19,95%

    Nii palju EL-i ettevõtetest kasutas 2025. aastal AI-tehnoloogiat; suurettevõtete hulgas on näitaja juba 55%.
    Allikas: Eurostat 2025

  • Eestis
    hostitud

    Kasvav kasutus tähendab rohkem tundlikke andmeid Eesti süsteemides. Kui mudeli töötlus toimub Eestis, jäävad need andmed EL-i jurisdiktsiooni.

Mida teeme sinu andmetega – ja mida mitte?

API-teenuses ja auditites töötleme ainult sinu esitatud sisendit (näiteks koodilõike või süsteemipäringuid) reaalajas vastuse või raporti genereerimiseks. Me ei kogu ega salvesta kliendi andmeid, ei treeni mudeleid nende peal edasi ega lekita neid kolmandatele osapooltele. Kogu mudelite töötlus hakkab toimuma Eestis.

API turvatööriistadele

Otspunkt järgib OpenAI chat-completions liidese kuju: olemasolev kood vajab tavaliselt ainult baasaadressi ja võtme vahetust. Ligipääs on võtmepõhine, limiitide ja kasutuspõhise arveldusega. Kasutajate andmeid ei koguta, ei treenita edasi ega lekita kolmandatele osapooltele. Oleme varajases etapis: avame ligipääsu taotluse alusel ja limiitidega. Kui vajad tervikpilti oma süsteemide seisust, telli küberaudit.

  • Võti ja limiididIga rakendus saab oma võtme, kululimiidi ja kasutusaruande.
  • Logideta režiimSoovi korral ei säilitata päringute sisu üldse – ainult tehnilised mõõdikud.
  • Sinu andmetega ei treenitaSinu päringuid ei kasutata mudelite treenimiseks ega anta kolmandatele osapooltele.
Planeeritava liidese näideAPI pole veel avalik
curl https://PILOODI-ENDPOINT.example/v1/chat/completions \
  -H "Authorization: Bearer SINU-VOTI" \
  -H "Content-Type: application/json" \
  -d '{"model": "PILOODI-MUDEL",
       "messages": [{"role": "user",
         "content": "Analüüsi see Nginxi konfig."}]}'

# Sama Pythonis (OpenAI teek)
from openai import OpenAI
client = OpenAI(base_url="https://PILOODI-ENDPOINT.example/v1", api_key="SINU-VOTI")
vastus = client.chat.completions.create(model="PILOODI-MUDEL", messages=[{"role": "user", "content": "Analüüsi see Nginxi konfig."}])

Kellele mudelid sobivad?

Hea sobivus

Ehitad turvatööriista, vajad eestikeelset turvatuge, pilve-AI keeldub su seaduslikust tööst või andmed ei tohi USA pilve minna.

Halb sobivus

Vajad üldist juturobotit, luuletajat või pildigeneraatorit – selleks sobib tavaline pilveteenus paremini ja odavamalt.

Millest hind sõltub?

  • API kasutus: tegelik maht, võtmepõhiste limiitidega. Hinnakiri selgub piloodi järel.
  • Erilahendused: erimudelid, mahud ja toe tase lepitakse eraldi kokku.

Kaardistuse järel saad hinna kirjas.

Mida mudelid ei tee?

  • Ei ebaseaduslikku abi: ründed võõraste vastu, pahavara ja pettused on välistatud.
  • Ei imesid: mudel võib eksida – kriitilised leiud käivad inimese käest läbi.
  • Ei asenda auditit: süsteemide kontrollimiseks telli agendipõhine küberaudit.

Küsimused mudelite kohta

Mis on tsenseerimata AI?

Mudelid hakkavad töötama meie enda riistvaral Eestis (riistvara tellitud) ega hakka sõltuma suurettevõtte pilvest. Päringud ei hakka liikuma Ameerika serveritesse ning reeglid paneme paika meie koos kliendiga.

Mida tähendab refusal-free?

Mudel ei keeldu meelevaldselt seaduslikust turvatööst, mille puhul pilveteenused tihti keelduvad. Ebaseaduslik tegevus on endiselt välistatud.

Kellele API mõeldud on?

Arendajatele, kes ehitavad turvatööriistu: skannereid, monitooringut, raportite koostajaid. Otspunkt ühildub OpenAI liidesega, ligipääs on võtmepõhine ja arveldus kasutuspõhine.

Milliseid mudeleid kasutate?

Avatud kaaludega alusmudel on Qwen3.8-27B. Tehisabiline häälestab refusal-free käitumise eraldi seadusliku turvatöö jaoks. Mudel hakkab töötama meie riistvaral Eestis (riistvara tellitud).

Miks pilv keeldub legitiimsest turvatööst?

Suured pilvemudelid rakendavad laiu keeldumisfiltreid, mis tabavad ka seaduslikku tööd: koodianalüüsi, ründepayload'ide uurimist või red-teaming-harjutusi. Meie mudelid vastavad neile sinu reeglite järgi ja seaduslikus raamis.

Mida te minu andmetega teete?

Töötleme ainult sinu esitatud sisendit reaalajas vastuse või raporti jaoks. Andmeid ei koguta, ei treenita edasi ega lekita kolmandatele osapooltele. Kogu mudelite töötlus hakkab toimuma Eestis.

Kuidas on lood AI Actiga?

Meie avatud kaaludega mudelitel põhinevad API-d liigituvad üldotstarbelise AI (GPAI) kategooriasse ega kuulu kõrge riskiga süsteemide hulka. Hoiame tehnilist dokumentatsiooni, hindame teadaolevaid riske ja hoiame kasutuse läbipaistva.

Kus mu andmed asuvad?

Tulevikus meie riistvaral Eestis – riistvara on tellitud. Soovi korral saab logideta režiimi, kus päringute sisu ei säilitata.

Millest hind sõltub?

API puhul kasutusmahust, erilahenduste puhul mahust ja toe tasemest. Tasuta kaardistuse järel saab selge pakkumise.

Kas API töötab OpenAI teekidega?

Planeeritud liides ühildub OpenAI teekidega. API pole veel avalik; tegeliku baasaadressi, mudelinime ja võtme saad pilootligipääsuga. Liidese kuju näited on API jaotises.
