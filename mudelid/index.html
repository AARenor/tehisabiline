Küberturbe API arendajatele

Kavandame OpenAI-ühilduvat liidest seadusliku turvatöö tööriistadele. API pole veel avalik; riistvara on tellitud ja Eesti majutus tulekul. Piloodis osalemist saad taotleda e-kirjaga.

Koostanud Arle Aron Reidma, Tehisabiline OÜ · Viimati sisuliselt uuendatud 12. oktoobril 2026

Kas API on saadaval ja kuidas sellele ligi saab?

Tehisabilise küberturbe API on arenduses ega ole veel avalik. Kavandame OpenAI chat-completions liidest turvatööriistadele; allolevad koodinäited kirjeldavad planeeritud päringu kuju, mitte töötavat avalikku otspunkti. Piloodis osalemiseks kirjuta tehisabiline@gmail.com ning kirjelda tööriista, kasutusjuhtu ja eeldatavat koormust. Ligipääsu, limiidid, hinna ja andmekäitluse tingimused lepime enne alustamist kirjalikult kokku.

Mis teeb mudeli küber-AI-ks?

Häälestame avatud kaaludega Qwen3.8-27B alusmudelit turvaülesannetele: haavatavused, logid, konfiguratsioonid, koodianalüüs ja oma süsteemide testimine kirjaliku loa alusel. Oma riistvara on tellitud ja majutus Eestis tulekul; API kaudu kasutamine on veel arenduses.

  • ArendusesAPI pole veel avalik; riistvara on tellitud, Eesti majutus kavandamisel.
  • Seaduslik turvatööKavandatud piirid on loa ja seadusliku kasutuse järgi.
  • OpenAI-ühilduv liidesChat-completions kuju on plaanis, mitte praegu kasutatav teenus.
  • Inimese kontrollOluliste leidude käsitsi ülevaatus on ettevõtte tööpõhimõte.

Mida kavandame turvatööks?

Need on ettevõtte arendusplaanid, mitte veel avaliku API tõendatud omadused.

  • Turvasisendite tugi. Eesmärk on võtta sisendiks näiteks CVE-ID, logilõik või konfiguratsioon; väljundeid tuleb inimesel hinnata.
  • Seaduslik turvatöö. Kavandatav kasutus on lubatud turvatöö kokkulepitud ulatuses; ebaseaduslik tegevus on välistatud.
  • Eesti majutus. Riistvara on tellitud, kuid majutus ja teenus Eestis on tulevikuplaan.
  • Andmekäitlus. Ettevõtte eesmärk on päringuid mitte säilitada ega treenimiseks kasutada; tegelikud tingimused lepitakse kokku enne pilooti.
  • Vastavus. Kasutus- ja dokumentatsioonikohustused hinnatakse enne teenuse avamist; see leht ei asenda õigusnõu.
  • Inimese kontroll. Oluliste leidude käsitsi ülevaatus on ettevõtte tööpõhimõte.

Kavandatav andmekäitlus ja piirid

Kuna API pole veel avalik, ei saa siin kirjeldada toimiva teenuse tegelikku andmekäitlust. Ettevõtte eesmärk on töödelda ainult päringus esitatud sisendit vastuse koostamiseks, mitte kasutada seda mudeli treenimiseks ega jagada kolmandatele osapooltele. Enne pilooti tuleb säilitamise, tehniliste logide, majutuse ja juurdepääsu täpsed tingimused osalejaga kokku leppida. Eesti majutus on plaan; riistvara on tellitud, kuid teenus pole veel seal töös.

Kavandatav API turvatööriistadele

Plaanis on OpenAI chat-completions liides. Allolev näide kirjeldab kavandatud päringu kuju; API pole veel avalik. Piloodis osalemiseks saada e-kiri, kirjeldades arendatavat tööriista, sisendite tüüpe ja eeldatavat kasutusmahtu. Enne ligipääsu lepime kokku kasutusulatuse, limiidid, andmekäitluse ja piloodi tingimused. Hinda pole veel avaldatud; arvelduse aluseks on kasutusmaht ja kokkulepitud limiidid. Kui vajad enda süsteemide kontrolli, vaata küberauditi ja pentestimise teenust.

  • LigipääsTaotluse alusel, pärast piloodi tingimuste kokkuleppimist.
  • Limiidid ja hindPole veel avaldatud; täpsustuvad piloodis.
  • AndmekäitlusTäpsed tingimused kinnitame enne pilooti kirjalikult.
Kavandatava liidese näide — mitte avalik otspunktAPI pole veel avalik
curl https://PILOODI-ENDPOINT.example/v1/chat/completions \
  -H "Authorization: Bearer SINU-VOTI" \
  -H "Content-Type: application/json" \
  -d '{"model": "PILOODI-MUDEL",
       "messages": [{"role": "user",
         "content": "Analüüsi seda Nginxi konfigi."}]}'

# Sama Pythonis (OpenAI teek)
from openai import OpenAI
client = OpenAI(base_url="https://PILOODI-ENDPOINT.example/v1", api_key="SINU-VOTI")
vastus = client.chat.completions.create(model="PILOODI-MUDEL", messages=[{"role": "user", "content": "Analüüsi seda Nginxi konfigi."}])

Kellele API sobib?

Hea sobivus

Ehitad küberturbetööriista ja vajad API kaudu mudelit seadusliku turvatöö jaoks.

Ei sobi

See API ei ole üldine juturobot ega pildi loomise teenus. See on mõeldud turvatööriistade arendajatele.

API kasutus

Ligipääsu ja hinnastuse tingimused täpsustuvad piloodi järel; arvelduse aluseks on kasutusmaht ja kokkulepitud limiidid.

Mida mudelid ei tee?

  • Ei ebaseaduslikku abi: ründed võõraste vastu, pahavara ja pettused on välistatud.
  • Ei imesid: mudel võib eksida – kriitilised leiud käivad inimese käest läbi.
  • Ei asenda auditit: süsteemide kontrollimiseks telli agendipõhine küberaudit.

Küsimused mudelite kohta

Mida tähendab keeldudeta ja piirangutega AI?

Keeldudeta (ehk tsenseerimata) tähendab, et mudel ei keeldu seaduslikust turvatööst – näiteks ründekoodi selgitamisest või oma süsteemide testimisest –, mille puhul pilveteenused tihti keelduvad. Piirangutega tähendab, et töö käib kirjaliku loa ja seadusliku raami piires: ebaseaduslikku tegevust mudel ei toeta.

Kas mudelid sõltuvad suurettevõtte pilvest?

API pole veel avalik. Eesti majutus on plaanis ja riistvara tellitud, kuid teenus pole veel seal töös; tegelik asukoht ja tingimused kinnitatakse enne pilooti.

Kellele API mõeldud on?

API on arenduses ega ole avalik. See on mõeldud turvatööriistade arendajatele; OpenAI chat-completions kujuga liides on plaanis. Piloodis osalemiseks kirjuta e-kiri, kirjeldades tööriista, kasutusjuhtu ja eeldatavat koormust.

Milliseid mudeleid kasutate?

Avatud kaaludega alusmudel on Qwen3.8-27B. Tehisabiline häälestab keeldudeta käitumise eraldi seadusliku turvatöö jaoks. Mudel hakkab töötama meie riistvaral Eestis (riistvara tellitud).

Miks pilv keeldub legitiimsest turvatööst?

Suured pilvemudelid rakendavad laiu keeldumisfiltreid, mis tabavad ka seaduslikku tööd: koodianalüüsi, ründekoodi uurimist või punase meeskonna (red teaming) harjutusi. Meie mudelid vastavad neile sinu reeglite järgi ja seaduslikus raamis.

Mida te minu andmetega teete?

API pole veel avalik. Ettevõtte eesmärk on kasutada päringu sisu vastuse koostamiseks, mitte mudeli treenimiseks ega kolmandatele osapooltele jagamiseks. Tegelikud säilitamise ja andmekäitluse tingimused lepitakse kokku enne pilooti.

Kuidas on lood AI Actiga?

Meie avatud kaaludega mudelitel põhinevad API-d liigituvad üldotstarbelise AI (GPAI) kategooriasse ega kuulu kõrge riskiga süsteemide hulka. Hoiame tehnilist dokumentatsiooni, hindame teadaolevaid riske ja hoiame kasutuse läbipaistvana.

Kus mu andmed asuvad?

Eesti majutus on plaanis ja riistvara tellitud, kuid API pole veel seal töös. Päringute tegelik asukoht ja logimise kord kinnitatakse enne pilooti.

Millest hind sõltub?

Hinda ega limiite pole veel avaldatud. Need täpsustuvad piloodis ning võivad sõltuda päringumahust, mudeli kasutusest ja kokkulepitud limiitidest.

Kas API töötab OpenAI teekidega?

OpenAI chat-completions kujuga liides on plaanis, kuid API pole veel avalik ega ühilduvust saa praegu katsetada. Koodinäide on kavandatud päringu kuju. Piloodis osalemist saad taotleda e-kirjaga.
