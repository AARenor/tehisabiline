12 kohta, kus küber-AI turvatööd kiirendab

Koodianalüüsist raportini: kasutusjuhud seadusliku turvatöö jaoks, igaühel kontrollpunkt ja mõõdik. Inimene kinnitab olulised leiud ning oma süsteeme testitakse ainult kirjaliku loa alusel. API arendatakse turvatööriistade jaoks ega ole veel avalik.

Milleks keeldudeta ja piirangutega küber-AI hea on?

Tehisabiline OÜ koondas siia 12 kasutusjuhtu, kus küberturbele häälestatud AI-mudel kiirendab seaduslikku turvatööd: logide uurimine, koodianalüüs, ründekoodi uurimine, süstirünnete testid, konfiguratsioonide audit, raportid ja muu. Üldine pilve-AI keeldub osast neist sageli ka siis, kui töö on seaduslik. Igal kasutusjuhul on kontrollpunkt ja mõõdik: olulise leiu kinnitab inimene ning oma süsteeme testitakse ainult kirjaliku loa alusel. API pole veel avalik; mudel hakkab töötama Eestis.

Kus see päriselt kasuks tuleb?

Kontrollpunkt: inimene kinnitab iga olulise otsuse. Auditi ulatuse leiad lehelt küberaudit: mida kontrollitakse.

Millest alustada?

  1. Vali üks kasutusjuht ning pane kirja lubatud ulatus.
  2. Sea kontrollpunkt: kes kinnitab leiud.
  3. Vali mõõdik: näiteks leidmisaeg või valideeritud leidude arv.
  4. Küsi API pilootligipääsu või alusta küberauditiga.

API arenduse hetkeseisu ja tehnilised andmed leiad API lehelt.

Millele see tugineb?

Kasutusjuhud lähtuvad laialt tunnustatud raamistikest, mida tasub ka ise lugeda: MITRE ATT&CK ründetehnikate taksonoomia, OWASP LLM Top 10 (sh prompt injection) ning UK NCSC juhised agentlike AI-süsteemide riskijuhtimiseks. Need raamistikud ei tõenda meie mudelite sooritust – need on taust, mille järgi kasutusjuhud on valitud.

Küberturvalisuse põhimõisted lühidalt

Turvatestimine

Oma süsteemide turvalisuse kontrollimine seaduslikus raamis ja omaniku loal – näiteks skaneerimine, konfiguratsioonide ülevaatus ja logide analüüs.

Pentest ehk läbitungimistest

Ühe sihtmärgi aktiivne murdmiskatse kokkulepitud mahus. Kitsam kui küberaudit, mis vaatab üle kogu turvaseisu.

Haavatavuste audit

Teadaolevate nõrkuste süsteemne kaardistamine koos parandusjärjekorraga. Meie küberaudit sisaldab seda koos ründetestide ja inimese ülevaatusega.

Küberaudit

Kogu küberturvalisuse ülevaatus: uuendused, ligipääsud, varundus, päised ja protsessid – tulemuseks parandusplaan, mitte hirmujutt.

Küsimused kasutusjuhtude kohta

Kas AI tohib turvatestimisega aidata?

Jah, seaduslikus raamis ja oma süsteemide puhul. Testimine toimub omaniku kirjaliku loa alusel.

Kas AI vastuseid saab alati usaldada?

Ei. Iga oluline leid tuleb üle kontrollida – ka auditites kinnitab inimene leiud.
