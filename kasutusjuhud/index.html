12 kavandatavat küber-AI kasutusjuhtu turvatöös

Milleks keeldudeta ja piirangutega küber-AI mõeldud on?

Tehisabiline OÜ koondas siia 12 kavandatavat kasutusjuhtu, mida arendatav mudel peaks seaduslikus turvatöös toetama: logide uurimine, koodianalüüs, konfiguratsioonide ülevaatus, raportite mustandid ja muu. Need on piloodi hüpoteesid, mitte kinnitatud võimekus ega mõõdetud ajavõit. Igal juhul on inimese kontrollpunkt ja mõõdik: olulise leiu kinnitab inimene ning oma süsteeme testitakse ainult kirjaliku loa alusel. API pole veel avalik; mudel hakkab töötama Eestis.

Kontrollpunkt: inimene kinnitab iga olulise otsuse. Auditi ulatuse leiad lehelt küberaudit: mida kontrollitakse.

Illustratsioon: kui palju aega üks töövoog nõuab?

Sisesta oma eeldused. Kalkulaator arvutab tunde ja nende väärtuse sinu tunnihinnaga. Tulemus on illustratsioon sinu enda eeldustest, mitte mõõdetud tulemus ega lubadus; mudel ja API pole veel avalikud. Andmed jäävad brauserisse.

Kokku tunde33,3 tundi
Väärtus tunnihinnaga1 333 €

Illustratsioon: tundide arv = ülesandeid × minutit × tööpäevi × osakaal / 60. See ei ole mõõdetud ajavõit ega lubadus.

Näide: 10 ülesannet päevas × 20 minutit × 20 tööpäeva × 50% = 33,3 tundi, mis 40 € tunnihinnaga on 1 333 €. Arvutus näitab sinu enda eeldusi, mitte tõendatud tulemust.

Millest alustada?

  1. Vali üks kasutusjuht ning pane kirja lubatud ulatus.
  2. Sea kontrollpunkt: kes kinnitab leiud.
  3. Vali mõõdik: näiteks leidmisaeg või valideeritud leidude arv.
  4. Küsi API pilootligipääsu või alusta küberauditiga.

API arenduse hetkeseisu ja tehnilised andmed leiad API lehelt.

Millele see tugineb?

Kasutusjuhud lähtuvad laialt tunnustatud raamistikest, mida tasub ka ise lugeda: MITRE ATT&CK ründetehnikate taksonoomia, OWASP LLM Top 10 (sh prompt injection), OWASP API Top 10 (2023) API-riskide kaart, OWASP WSTG v4.2 veebirakenduse testide alusena ning UK NCSC juhised agentlike AI-süsteemide riskijuhtimiseks. Need raamistikud ei tõenda meie mudelite sooritust – need on taust, mille järgi kasutusjuhud on valitud. Põhimõisted on ühes kohas: küberturbe sõnastik.

Küsimused kasutusjuhtude kohta

Kas AI tohib turvatestimisega aidata?

Jah, seaduslikus raamis ja oma süsteemide puhul. Testimine toimub omaniku kirjaliku loa alusel.

Kas AI vastuseid saab alati usaldada?

Ei. Iga oluline leid tuleb üle kontrollida – ka auditites kinnitab inimene leiud.
